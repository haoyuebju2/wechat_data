# wechat_data · 微信数据本机工具

基于固定版本 WeChatDataAnalysis 的本机隐私改造：查看、搜索、分析和导出微信数据，支持本地新消息自动更新，以及用户主动控制的 AI 资料授权。

本仓库提交的是**改造源码、变更范围与新增字节、固定上游引用、安装脚本**。上游完整源码、聊天记录、媒体、密钥、运行日志、浏览器配置和运行时二进制均不上传。安装时获取并校验固定上游源码，再重建当前改造版本。

## 安装与启动

普通用户从 [v0.1.4 Release](https://github.com/haoyuebju2/wechat_data/releases/tag/v0.1.4) 下载 `WeChatDataMonitor-0.1.4-Windows-x64-Offline-Setup.exe`，核对 SHA-256 后运行。这是完整离线安装包，已经包含桌面程序、Python、依赖和界面，安装时不下载或编译组件。标准向导显示当前组件、百分比进度、详情和完成页；安装后直接使用快捷方式或 `WeChatDataMonitor.exe`，并提供卸载入口。首次配置本程序的防火墙规则需要管理员确认。未签名，使用新空目录安装；用户数据与程序分开保存。[更新内容与限制](docs/RELEASE_0.1.4.md)。旧 v0.1.0 联网安装器不再推荐。

以下为直接源码安装方式：

Windows x64，需预先安装 Node.js/npm。项目放在本机固定磁盘、非共享且非云同步目录。

```powershell
git clone https://github.com/haoyuebju2/wechat_data.git
cd wechat_data
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-Offline.ps1
```

安装阶段需要访问公开源码与依赖站点。完成后，以管理员身份运行一次 `Enable-Offline-Firewall.cmd`，再双击 `Start-Offline.cmd`。启动器校验专用程序的断网规则与运行文件摘要；日常使用不需管理员身份。

已有独立开发环境的行为测试和 UI 构建通过。完整首次依赖安装仍需在新的 Windows 环境验收；不要把既有环境验证等同于全新安装成功。[完整安装说明](docs/PUBLIC_SETUP.md)。

## 功能

“原图记录”支持在窗口内拖动；拖到任意边缘后收成半圆，点击展开，拖离边缘恢复完整入口。程序重启后记住位置，拖动不会清零新获取数。

- 原界面及本地数据库解密、聊天/联系人等解析、搜索和 JSON/TXT/HTML/Excel 导出。
- 右上角显示自动原图下载记录入口及新获取数量；打开后清零新获取计数，可分页查看和清空历史。历史保存在本机，清空不删除图片、不改变下载队列。
- 点图预览时优选本机高清版本。设置 → 聊天与媒体支持原图按需获取，以及收到新图片后自动下载：可选全部对话，或按账号勾选指定私聊/群聊。独立组件直连微信节点，本机解密、校验和缓存；不调用 WxCDN 等第三方图片服务，不操作微信界面。新安装默认关闭自动下载，不回溯历史图片；后台串行执行，失败最多尝试 3 次。
- 原图请求没有可用文件时，可获取同一消息的清晰版本。WXGF 会先按消息 MD5 校验源数据，再获取同一资源的 JPEG 转换预览、与本机图片比对，并标为“清晰转换图（非原图文件）”；不会把转换后的 JPEG 冒充原文件。记录中原图与清晰图分别统计。
- 本地数据库/WAL 有变化即触发认证、解密与校验，通过本机事件流自动更新聊天页面；另有一秒兜底检查。首次准备缓存、微信落盘和机器负载影响实际时延。
- 移除 Pro、套餐和高级版推广入口，不加载未审查的上游原生授权核心。
- 本机 OpenAI 兼容模型接口默认关闭，仅处理明确提交的预览内容。
- ChatGPT/Codex MCP 连接仅能读取用户预览并明确授权的一份资料，十分钟有效、只读一次、可撤销。回答在 ChatGPT 客户端显示；其模型仍在云端，不能把这一步称为完全离线推理。

## 隐私与限制

运行时禁用配置上传兜底、遥测、在线授权、第三方媒体补齐、在线更新和模型自动下载。后端仅监听本机并认证；拒绝网络文件、外部进程与未审查的上游 DLL/EXE/PYD。系统防火墙形成额外阻断层。

开启原图下载后，单独的本机编译组件是联网例外；查看器和 Python 后端仍保持系统断网。兼容协议使用 HTTP 载体，资源标识与 CDN 鉴权元数据没有 TLS 保护，图片内容仍为密文，图片解密密钥不提交给下载组件或节点。不能把该模式称为完全离线或绝对零泄露。

不作绝对零泄露保证。Windows、运行时、依赖、管理员、同一用户的其他程序、云同步和主动分享仍在信任边界内。部分专有媒体、原生语音、实时 WCDB、WEC1 导出等未安全替换的组件仍关闭或不可用；这不是上游全部功能均已完成的声明。[安全边界](docs/PUBLIC_SECURITY.md)。
