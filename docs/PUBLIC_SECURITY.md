# 数据与网络边界

GitHub 仓库只保存审核过的改造源码、版本差分和安装说明。聊天数据库、媒体、密钥、AI 设置、一次性授权资料、运行环境、浏览器配置、日志和实机审计记录不提交，也不能通过 Git 历史泄露。

应用运行时使用专用 Python/Electron。后端仅监听本机，验证随机凭证、来源与 Host；拒绝网络文件路径、外部进程、未审查的上游原生组件和后台外网请求。启动器必须检查对应程序的系统防火墙阻断规则和固定运行文件摘要。

本机模型连接默认关闭，仅显式请求期间允许访问配置的数字回环地址和指定端口，禁止代理与跳转。该本机服务自己是否联网，由其配置决定。ChatGPT/Codex 的 MCP 仅提供用户预览并明确允许云端处理的一份资料，十分钟有效、一次使用即失效，可撤销；ChatGPT 客户端会将已授权内容交给云端模型。

文件变化触发聊天快照更新，WAL 中只有校验通过的已提交消息才显示。已认证页面可复用，每个变化页重新进行 HMAC 验证；SQLite 检查通过后原子发布，失败保留旧数据。界面通过本机事件流自动刷新。微信未落盘、首次准备缓存、文件占用及机器负载会影响时延。

图片预览优先比较本机已有画质。原图获取和收到新图后的自动下载默认关闭；可在设置中选择全部对话，或按账号勾选私聊、群聊。只处理启用后已发布到本机校验快照的新图片，不回溯历史；后台通过持久队列串行下载，最多尝试 3 次。范围取消后不再提交后续分片；已提交请求最多在组件超时后返回。点图获取仍可单独使用。不自动操作微信，不调用 WxCDN 等第三方服务；旧链接上的 fetch_remote 参数不能启用原上游服务。

自动下载的索引和下载线程与聊天快照发布分开，按已变更数据库的 local_id 增量读取，不在空闲时遍历消息正文。每个账号的待处理队列最多 10,000 项，满额时保留读取位置，空出后继续；重启后继续未完成任务。范围设置以用户级 DPAPI 保存；队列仅在本机记录账号、对话和消息标识，不包含聊天正文、密钥或 CDN 凭据。

自动下载完成后，在本机数据库另存时间、对话标识、结果和尝试次数，供右下角记录浮窗查看。仅实际新下载成功计入“新获取”；本地已有、失败、取消和旧版完成记录不计入。打开时按已取得的序号边界标为已读，不会误清除后来完成的新记录。历史可分页查看，隐私模式会隐藏对话和账号；清空仅删除历史元数据，不删除图片、不清除任务或增量游标。升级时将仍保留的旧任务标为旧记录，不推断它们是否曾联网下载。记录变动通过认证的本机事件流通知页面，不主动上传历史。

原图获取由单独从可审查 C# 源码在本机编译的下载组件承担，属于明确的联网例外。Python 后端及 Electron 的系统断网规则不变。组件只处理本次启动随机能力凭证绑定、限时且用户级 DPAPI 加密的文件队列请求，目标为从账号匹配的官方微信进程读取的公网 IPv4 CDN 节点，固定端口 443 和 /download 路径，拒绝 DNS、代理、跳转、任意 URL 与非图片下载；Windows Job 限制它只能有一个进程并限制内存。该组件不读取微信配置、数据库或图片解密密钥。

兼容协议的 HTTP 载体不是 HTTPS，CDN 资源标识和鉴权元数据没有 TLS 保护；媒体内容使用 AES 密文下载，在后端本机解密，通过分片边界、完整长度、填充、消息 MD5 和图片格式检查后才缓存。失败保留已有图片，不降低校验要求。设置说明保留这一传输限制，不宣称全程离线或零泄露。

CDN 参数不保证一直以完整响应驻留在微信内存。成功获得的参数可用用户级 DPAPI 加密缓存，绑定账号、来源路径、当前微信进程代次，最多 24 小时；进程重启、切换账号、服务端拒绝或不兼容版本可能使获取失败。页面明确提示失败并保留本地图。

代码检查、合成测试、连接表采样、系统阻断探测和真实端到端验收是不同证据。Windows、运行时、依赖、管理员、同一用户的其他程序、云同步与主动分享仍在信任边界内，不保证绝对零泄露。
