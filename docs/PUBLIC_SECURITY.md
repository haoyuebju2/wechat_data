# 数据与网络边界

GitHub 仓库只保存审核过的改造源码、版本差分和安装说明。聊天数据库、媒体、密钥、AI 设置、一次性授权资料、运行环境、浏览器配置、日志和实机审计记录不提交，也不能通过 Git 历史泄露。

应用运行时使用专用 Python/Electron。后端仅监听本机，验证随机凭证、来源与 Host；拒绝网络文件路径、外部进程、未审查的上游原生组件和后台外网请求。启动器必须检查对应程序的系统防火墙阻断规则和固定运行文件摘要。

本机模型连接默认关闭，仅显式请求期间允许访问配置的数字回环地址和指定端口，禁止代理与跳转。该本机服务自己是否联网，由其配置决定。ChatGPT/Codex 的 MCP 仅提供用户预览并明确允许云端处理的一份资料，十分钟有效、一次使用即失效，可撤销；ChatGPT 客户端会将已授权内容交给云端模型。

文件变化触发聊天快照更新，WAL 中只有校验通过的已提交消息才显示。已认证页面可复用，每个变化页重新进行 HMAC 验证；SQLite 检查通过后原子发布，失败保留旧数据。界面通过本机事件流自动刷新。微信未落盘、首次准备缓存、文件占用及机器负载会影响时延。

图片预览只对当前查看的图片重新请求本机资源，比较本机已有画质，不后台批量读取整库、不触发第三方 CDN，也不将已关闭的付费获取开关当成可用功能。旧链接上的远程获取参数不会重新启用下载。微信尚未下载的原图不能通过离线解析凭空取得；自动操作微信客户端下载尚未实现或启用。

代码检查、合成测试、连接表采样、系统阻断探测和真实端到端验收是不同证据。Windows、运行时、依赖、管理员、同一用户的其他程序、云同步与主动分享仍在信任边界内，不保证绝对零泄露。
