# 微信数据本机工具 v0.1.0

首个正式编号版本，适用于 Windows x64。基于固定 WeChatDataAnalysis 源码进行本机隐私改造，不保证所有微信 4.x 版本和所有媒体均可解析。

## 下载与安装

下载 `WeChatDataMonitor-0.1.0-Windows-x64-Setup.exe`，对照 `SHA256SUMS.txt` 核验。它是**联网安装器**，不是离线完整包：在你选择的空目录里下载并校验固定的 Node.js、Python、上游源码与依赖，再构建本机程序。安装阶段需要访问 GitHub、Python、Node.js、npm 和 PyPI。安装包未做代码签名，不冒称有受信发布者签名。

安装时不需要事先配置 Git、Python 或 Node。首次防火墙配置需要 Windows 管理员确认；如果取消或失败，运行安装目录的 `Enable-Offline-Firewall.cmd` 完成后再启动。正常启动使用桌面 / 开始菜单快捷方式，或安装目录中的 `WeChatDataMonitor.exe`。可选择登录 Windows 后自动启动；在 `shell:startup` 删除相应快捷方式即可取消。

`ReviewedSources.zip` 是经过发布清单审核的改造源码，不是免安装运行包。GitHub 自动生成的 Source code 同样是源码。

## 本版内容

- 本机查看、搜索、导出微信聊天；数据库变化经本机认证与校验后更新页面。
- 本机只读密钥获取与数据库解密；关闭配置上传、遥测、在线授权、后台更新和第三方媒体补齐路径。
- 支持点图获取高清图，以及指定对话 / 全部对话的新图片后台自动下载。
- 修复部分 WXGF 消息的清晰预览；清晰转换图明确标注“非原图文件”。
- 右上角查看下载记录、新获取数量；打开后清零新计数，清空历史不删除媒体和下载任务。
- 移除默认菜单栏与 Pro 推广入口；提供受控本机模型连接及单次资料授权 MCP。
- 新增可审查源码构建的联网安装器、专用运行环境、主程序 EXE 与快捷方式。

## 隐私与已知限制

安装文件只包含审核清单中的改造源码，不包含开发机聊天、账号、密钥、媒体、日志或浏览器资料；也不内置上游完整源码或预编译私有组件。上游源码和运行时在使用者安装时单独取得并校验，保留各自许可说明，不重新授予第三方许可。

Python 和 Electron 正常运行保持系统断网规则。高清图片组件是明确的联网例外，直连微信节点；兼容协议的 HTTP 请求元数据没有 TLS 保护。AI 云端客户端读取授权资料后会把所选内容交给相应模型服务。不是完全离线、绝对零泄露或全部依赖源码审计的承诺。

资源过期、微信版本不兼容或图片校验失败时可能只有本地小图。没有持续无人值守 AI 群日报能力；单次授权 MCP 不提供任意数据库搜索。部分专有媒体和原生语音能力仍不可用。

## 更新、卸载与回退

本版安装器只接受新建空目录，拒绝覆盖旧安装；没有自动原地升级和自动数据迁移。更新时保留旧目录，在新目录安装并核对自己的数据源；新旧实例不能同时占用同一端口。失败后退出新版再启动旧版。密钥等 DPAPI 配置受 Windows 用户保护，跨用户 / 跨机不能按普通配置文件直接搬用。

需要保留旧下载历史和缓存时，应先按版本核对迁移。删除前先保留需要的数据。当前没有自动卸载器；删除自启及应用快捷方式后，确认不再需要该版本数据，再手动处理该版本目录与对应专用防火墙规则，不操作微信原始目录。
