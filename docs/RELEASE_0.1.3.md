# 微信数据本机工具 v0.1.3 · 完整离线安装版

本版本替代 v0.1.0 联网安装器。下载一个 `WeChatDataMonitor-0.1.3-Windows-x64-Offline-Setup.exe` 即可安装，不在安装期间下载 Node.js、Python、依赖或源码，也不在用户电脑上编译程序。运行环境、依赖库、聊天界面、后端及图片组件均已包含。

## 安装与使用

按 `SHA256SUMS.txt` 核对安装文件，运行后依次选择安装位置、桌面快捷方式和可选的登录后自启。界面显示当前组件、文件、百分比进度条和可展开详情。完成页明确显示安装完成，并可直接启动软件。安装器会请求一次管理员确认，为本应用及内置 Python 配置专用防火墙规则，不改变其他程序的网络权限。

软件是实际打包的桌面程序。安装后从“微信数据本机工具”快捷方式或安装目录的 `WeChatDataMonitor.exe` 打开，不需要运行 CMD、PowerShell 启动器或手工安装 Python / Node。首次运行需配置自己的微信账号目录和密钥。安装文件和程序尚未进行代码签名。

支持从 Windows 的应用列表或开始菜单卸载。程序文件与 `%APPDATA%\WeChatDataMonitor` 用户数据分开；卸载程序不删除该目录中的聊天缓存、密钥或授权设置。保留旧版本安装目录，新版本使用空目录安装；本版本不提供聊天数据格式的跨版本自动迁移承诺。

## 修复和改进

- 改用标准 Inno Setup 安装向导：欢迎、目标位置、选项、安装进度、完成及卸载入口。
- 完整离线分发，取消安装时的下载、pip、npm 和源码构建步骤。
- 修复打包后 `app.asar` 被 Electron 虚拟文件接口误判为不存在、导致程序无法打开的问题；改用真实文件接口完成 SHA-256 校验，没有关闭完整性检查。
- 启动时显示检查提示，系统隔离检查异步执行；失败时标明具体阶段，继续拒绝不满足隔离要求的启动。
- 同一用户只运行一个打包实例，避免重复点击引起端口冲突。
- 防火墙检查显式使用 Windows 系统模块路径，避免从开发环境继承不兼容模块路径；离线安装不调用 `Get-FileHash`。
- 用户数据移出程序目录；单次授权 MCP 按相同用户数据目录读取，不扩大授权范围。

## 验证与边界

已实际安装完整离线桌面版，确认生成主程序、快捷方式、卸载入口和 6 条专用阻断规则。已对本机安装执行启动故障定位及修复，实际打开到数据库解密页面。保留开发环境和已有聊天数据，没有把这些数据放入离线安装包。打包相关改动后通过 90 项后端测试和 2 项桌面会话边界测试；另核对真实文件与 Electron ASAR 文件接口差异。

安装成功和界面打开不代表所有微信版本、密钥获取、每张图片、模型推理均通过验收。未证明所有 Windows 机器、卸载或系统升级情形；安装包未经过独立安全审计。

普通查看、搜索、解密和导出保持本机处理。主动开启高清图片下载后，独立组件仍会连接微信节点，HTTP 元数据没有 TLS 保护；主动授权云端 AI 后，所选资料进入相应模型服务。完整离线安装不等于所有可选功能永远不联网，也不是绝对零泄露保证。
