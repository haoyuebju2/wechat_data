# 微信数据本机工具 v0.1.4 · 可拖动的原图记录

完整离线安装包：`WeChatDataMonitor-0.1.4-Windows-x64-Offline-Setup.exe`。包含桌面程序、Python、依赖和界面，安装时不下载或编译组件。标准安装向导显示当前组件和百分比，保留完成页、卸载入口及首次专用防火墙配置。

## 原图记录入口

- 按住“原图记录”拖动，可在程序窗口内自由放置。
- 拖到左、右、上、下边缘并松开，会吸附为露出一半的圆形入口；有新记录时显示小绿点。
- 点击半圆会展开完整入口和记录面板；关闭面板或点击外部区域后重新收起。
- 按住半圆拖离边缘，会恢复完整入口。拖动不会打开历史或清零新获取计数。
- 位置及贴边状态保存在本机，重新启动后恢复；缩小窗口时保持入口可见，展开面板限制在窗口内。
- 历史、新获取计数、分页和清空历史的行为保持一致。打开记录后清零新获取数；清空历史不删除图片或下载任务。

桌面版使用独立的小型位置文件，仅保存比例坐标和贴边方向。保持原有临时浏览会话，不为记住位置而开启整个聊天网页的持久缓存。不新增外部网络请求、轮询定时器或依赖。

## 验证

原图记录组件的 14 项行为测试通过，包括拖动不误点、四边收起与拖出、恢复位置、取消拖动、窗口缩放和原有历史计数。桌面位置存储及会话边界的 4 项测试通过。构建后的实际界面使用虚构记录验证四边均只露出 24 像素半圆、展开面板不越界，聊天 / AI / 图片范围设置和外部请求阻断检查通过。

安装、联网例外、数据目录和兼容范围延续 v0.1.3：普通查看、解密和导出保持本机处理；主动启用高清图片或云端模型时，相应联网边界仍适用。安装器尚未签名。程序文件与 `%APPDATA%\WeChatDataMonitor` 用户资料分开，卸载保留资料，不承诺跨版本数据迁移或所有 Windows / 微信版本兼容。

附件不含开发机聊天、媒体、密钥、日志或浏览器配置。第三方运行时和依赖保留原许可与通知。源码安装与图文教程见项目 README 和飞书文档。
