# 微信数据本机工具 v0.1.5 · 首次获取数据库密钥修复

完整离线安装包：`WeChatDataMonitor-0.1.5-Windows-x64-Offline-Setup.exe`。程序、Python、依赖和界面均已包含，安装时不下载或编译。

## 新用户怎么使用

1. 在自己的 Windows 10 / 11 x64 电脑打开微信，登录自己的目标账号。
2. 安装完整离线 EXE；首次管理员确认只用于配置本应用防火墙规则。
3. 进入工具首页检测账号，选择自己的账号，核对解密页的 `db_storage` 路径。
4. 点击“一键获取数据库密钥”→“开始只读获取”，等待认证成功，再点击“开始解密”。无需预先从其他电脑拿密钥。
5. 进入聊天页查看文字；图片密钥、媒体与高清图范围按教程另行设置。密钥只在本机使用和加密保存，不把他人或开发者的密钥放入安装包。

## 修复

- 先收集所有微信进程中的候选，再优先验证二进制候选，普通文本留作后备。解决大量 32 字符普通文本先耗尽验证时间的问题，不降低数据库认证要求。
- Windows 密钥扫描移到后台线程，获取期间健康接口和其他页面可响应；客户端停止请求时通知扫描结束。
- 获取页面明确标注本机只读扫描，成功不再误称 Hook。失败不再诱导用户切换到本版本没有提供的 DLL Hook。
- 自动获取请求不作隐式重试，避免重复启动昂贵扫描。
- 保留原图记录拖动、四边半圆收起、点击展开、拖出恢复和本机位置记忆。

## 实测与范围

在 Windows 微信 **4.1.15.13** 上，以空资料目录测试，并用审计钩子禁止读取任何已保存的 `account_keys.json`：源码流程约 55 秒取得密钥；完整打包后端使用安装版同版内置 Python，经本机认证 HTTP 接口约 58 秒取得密钥。消息库与会话库认证通过，实际解密一份会话数据库并通过 SQLite `quick_check`。扫描期间 182 次健康请求均成功，最慢约 0.178 秒。

这证明当前本机微信版本可首次获取，不是只复用开发机旧密钥；没有在其他电脑、所有微信 4.x 版本或所有权限组合上验证。微信需保持登录，路径必须属于同一账号，系统也需允许只读访问微信进程。获取失败时显示原因，不承诺任意新版微信永久兼容。

普通解密、查看与导出保持本机处理；高清图片和主动授权的云端模型仍适用各自联网边界。安装器未签名，保留标准进度向导、卸载入口、资料目录和原有安全限制。附件不含开发机账号、聊天、图片、密钥、日志或用户配置。
