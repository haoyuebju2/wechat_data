# 微信数据本机工具 v0.1.6 · 原图下载恢复与失败提示

完整离线安装包：`WeChatDataMonitor-0.1.6-Windows-x64-Offline-Setup.exe`。Windows 10 / 11 x64，内置运行环境，安装时不下载或编译组件。

## 修复

- 已注册账号的微信下载节点或认证信息变化后，下载组件从固定位置的当前用户 DPAPI 会话缓存重新载入，不再只认启动时的旧地址。
- 新节点必须存在于该账号独立缓存中；请求本身的地址列表不能授权新地址。保留账号身份匹配、过期检查、公开 IPv4、条数和包体限制。
- 节点传输失败或会话未载入时，后端会在原有时间上限内刷新微信会话并重试一次。
- 已验证的高清缓存优先于短时失败记录，避免下载已恢复后仍继续提示不可用。
- 短时失败保留具体的安全提示及重试等待时间，不再一律显示“原图暂不可用”。

## 图片质量说明

原图接口被微信节点拒绝时，工具可以尝试同一消息的清晰版本。WXGF 源文件须通过消息 MD5 认证，JPEG 转换版本还须与本地缩略图进行受限图像比对，才保存为“清晰转换图”，显示尺寸并明确标注“非原图文件”。本次对应图片已取得 1280×2844 清晰转换版本；这不代表微信节点已经提供原始文件，也不代表所有图片都可补齐。

## 验证

98 项后端测试通过。C# 下载组件离线行为测试覆盖同账号缓存更新、新地址须由独立缓存授权、地址与认证身份绑定、未知账号拒绝、缓存过期、私有地址及畸形认证字段拒绝；测试未发起网络请求。保留原有图片完整性校验、外网阻断和第三方服务禁用策略。

首次数据库密钥获取沿用 v0.1.5，在微信 4.1.15.13 上的空密钥目录获取、消息 / 会话库认证及数据库解密证据仍适用；其他电脑及微信版本需实测。

普通解密、查看和导出保持本机处理。主动开启高清图片下载后，独立组件仍会连接微信节点；兼容 HTTP 载体的元数据没有 TLS 保护。主动使用云端模型另受所选资料授权范围限制。安装包未签名，不包含开发机聊天、媒体、密钥、日志或用户配置。
